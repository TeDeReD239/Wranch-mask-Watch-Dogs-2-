# 🎭 WRENCH MASK — маска ДеdSec для M5StickC Plus 2

Живая маска Вренча из **Watch Dogs 2**: маска на экране стика, которая моргает,
косится по сторонам, пугается резких звуков, злится от ударов по кузову,
смотрит в повороты и управляется с телефона через хакерскую веб-панель.
                                         
## ✨ Фичи

### 😵 Эмоции
- **17 эмоций** крупными символами (`^ ^`, `\ /`, `Z Z`, `> <` ...)
- **Рандомное моргание**: два стиля закрытых глаз (`- -` и `~ ~`), случайный интервал и длительность, двойное моргание
- **Зрачки**: глаза иногда «косятся» влево-вправо перед морганием
- **Глитч-эффект** при смене эмоций — фирменный стиль DedSec

### 🎛 4 режима работы
| Режим | Что делает |
|-------|------------|
| **AUTO** | Эмоции меняются сами, случайно каждые 8–15 сек |
| **BTN**  | Ручной: эмоции листаются кнопкой B |
| **MIC**  | Музыка: реакция на громкость, 3 категории (тихо / средне / громко) |
| **CAR**  | Езда: IMU — взгляд в поворот, испуг при тормозе, натуга при разгоне, сон и охрана кузова на парковке |

### 🔴 Испуг
- В **MIC**: резкий громкий звук → **красный фон** на 2 сек (`! !` → `\ /`)
- Срабатывает **один раз** за вход в громкую зону (гистерезис: вход ≥ 66%, повторный взвод ≤ 40%)
- В **CAR**: удар по кузову в режиме охраны → такой же красный испуг

### 📱 Веб-панель (Wi-Fi)
- Стик поднимает свою точку **WRENCH_DEDSEC** (пароль `dedsec2016`)
- **Captive portal**: телефон сам выкидывает уведомление «Вход в сеть» после подключения
- Тёмная DedSec-панель: живое лицо, громкость, батарея, все 17 эмоций, режимы, слайдеры настроек
- Wi-Fi **по требованию** (долгое A) и автовыключение через 5 минут — экономия батареи

### 💾 Память
Режим, переворот экрана и все настройки слайдеров хранятся в **Preferences** и переживают перезагрузку.
