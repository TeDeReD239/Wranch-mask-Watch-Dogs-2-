# 🎭 WRENCH MASK — маска Вренча из Watch Dogs 2 для M5StickC Plus 2

Живая маска Вренча из **Watch Dogs**: лицо на экране стика, которое моргает, косится по сторонам, пугается резких звуков, злится от ударов по кузову и управляется с телефона.

---

## ✨ Возможности

### 😵 Эмоции

17 эмоций: DEAD, DIZZY, WINK, GRIT, SASS, STAR, HAPPY, ANGRY, SAD, MEH, LOOPY, CALM, PAIN, CONFUSED, SLEEPY, CRY, ALERT

### 👁 Живая анимация

- **Моргание**: случайные интервалы, двойное моргание
- **Взгляд**: глаза косятся перед морганием
- **Глитч-эффект**: случайные символы при смене эмоций

### 🎛 Режимы работы

| Режим | Описание |
|-------|----------|
| **AUTO** | Эмоции меняются случайно каждые 8–15 сек |
| **BTN** | Ручная смена эмоций кнопкой B |
| **MIC** | Реакция на громкость музыки/звука |
| **CAR** | Реакция на движение авто (IMU) |

### 🔴 Испуг

Красный фон при:
- Громком звуке (MIC режим)
- Ударе по кузову (CAR режим)

### 📱 Веб-панель (Wi-Fi)

**Подключение:**
- SSID: `WRENCH_DEDSEC`
- Пароль: `dedsec2016`
- IP: `192.168.4.1`

**Функции:**
- Выбор режима и эмоций
- Настройка чувствительности микрофона
- Регулировка яркости
- Переворот экрана
- Калибровка IMU

**Экономия энергии:**
- Wi-Fi включается долгим нажатием кнопки A (800 мс)
- Автоматическое выключение через 5 минут без активности

### 💾 Сохранение настроек

Запоминаются: режим, переворот экрана, настройки микрофона, яркость, калибровка IMU

---

## 🚀 Установка

1. Установите [PlatformIO](https://platformio.org/)
2. Откройте проект в VS Code
3. Нажмите **Build** и **Upload**

---

## 🎮 Управление

- **Кнопка A (коротко)**: переключение режимов AUTO → MIC → CAR → BTN
- **Кнопка A (долго, 800 мс)**: вкл/выкл Wi-Fi
- **Кнопка B**: смена эмоции (в режиме BTN)

## 🏗 Структура проекта

```
src/

├── config.h           # Конфигурация и пины
├── emotions.h         # 17 эмоций и символы
├── animation.h        # Моргание, взгляд, глитчи

├── mic.h              # Микрофон и FFT
├── car.h              # IMU и логика авто
├── web.h              # Веб-сервер и панель
└── prefs.h            # Сохранение настроек
```

## 🔧 Настройки

- Тайминги моргания
- Параметры IMU
